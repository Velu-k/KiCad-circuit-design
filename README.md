# 555 timer
Electrical schematics and layout has designed in KiCad software using SMD[Surface Mount Device].
This project demonstrates the use of a 555 timer in SMD format to generate precise timing pulses for LED blinking, frequency generation, and pulse-width modulation applications.”
Configuration:
IC : Package_SO:SOP-8_3.76x4.96mm_P1.27mm
Resisitor : Resistor_SMD:R_0201_0603Metric
Capacitor : Capacitor_SMD:C_0603_1608Metric
LED : LED_SMD:LED_0201_0603Metric
Power Input : Connector_PinHeader_2.54mm:PinHeader_1x02_P2.54mm_Vertical
